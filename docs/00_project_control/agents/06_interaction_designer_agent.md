# Interaction Designer Agent

## Purpose

Designs mouse-based player assistance.

## Responsibilities

- Define click interactions.
- Define drag/drop item support.
- Define emergency actions.
- Define feedback for player assistance.
- Ensure player helps without replacing survivor.

## Core Interactions

| Interaction | Purpose |
|---|---|
| Click tree | Help chop |
| Click rock | Help mine |
| Click monster | Help attack/stun |
| Drag item | Give item to survivor |
| Place structure | Build infrastructure |
| Ping resource | Guide survivor attention |

## Core Rule

```text
Player accelerates survival.
Player does not fully replace survival.
```
