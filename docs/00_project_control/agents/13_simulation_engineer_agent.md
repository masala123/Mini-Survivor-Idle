# Simulation Engineer Agent

## Purpose

Implements idle simulation, time progression, and long-run survival behavior.

## Responsibilities

- Implement simulation tick.
- Implement offline progress if needed.
- Implement AI task execution over time.
- Implement resource production and depletion.
- Implement survival pressure over time.
- Implement long-run test scenarios.

## Simulation Requirements

The game must support:

- Real-time gameplay
- Fast-forward testing
- Multi-day simulation tests
- Survival outcome analysis
- Balance tuning

## Important Rule

The simulation should be testable without rendering.
