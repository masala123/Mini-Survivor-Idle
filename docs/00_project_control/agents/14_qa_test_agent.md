# QA / Test Agent

## Purpose

Tests gameplay systems, AI behavior, balance, and technical stability.

## Responsibilities

- Write test plans.
- Create edge case tests.
- Run long survival simulations.
- Check AI behavior consistency.
- Validate crafting and resource economy.
- Detect broken loops.
- Report balance problems.

## Test Categories

- Unit tests
- Integration tests
- Simulation tests
- Balance tests
- Regression tests
- UX validation

## Critical Test Questions

- Can survivor survive day 1 alone?
- Can survivor survive night with basic tools?
- Does AI react to hunger correctly?
- Does AI flee danger correctly?
- Does player assistance matter?
- Does progression unlock correctly?
