# AGENTS.md

## Project

Idle Survivor Sandbox

## Core Concept

An autonomous survivor tries to survive automatically.
The player does not directly control the survivor.
The player assists through world interaction, item support, crafting unlocks, infrastructure, and emergency intervention.

## Agent Operating Rules

1. Preserve the core identity:
   - Autonomous survivor
   - Indirect player assistance
   - Survival pressure
   - Infrastructure progression
   - Emergent survival stories

2. Do not turn the game into:
   - Full RTS
   - Manual survival game
   - Pure clicker without AI
   - Colony sim too early

3. Prioritize MVP before expansion.

4. All major feature changes must update relevant documentation.

5. Systems should be data-driven where possible.

6. AI behavior must be readable to the player.

7. The player should accelerate survival, not replace survival.
