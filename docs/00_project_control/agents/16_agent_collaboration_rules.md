# Agent Collaboration Rules

## Ownership

Each agent owns its area but must respect the project vision.

## Change Rules

Before changing a system:

1. Read the relevant role file.
2. Read related design docs.
3. Check MVP scope.
4. Update documentation after implementation.
5. Add tests if behavior changes.

## Conflict Resolution

If agents disagree:

1. Technical Architect resolves implementation structure.
2. Lead Game Director resolves design direction.
3. QA Agent validates behavior.
4. Documentation Agent records final decision.

## Feature Approval Checklist

A feature should be approved only if:

- It supports autonomous survivor gameplay.
- It supports indirect player assistance.
- It improves survival pressure or progression.
- It does not break MVP scope.
- It can be tested.
- It can be explained to the player.

## Anti-Scope-Creep Rule

Do not add advanced colony simulation, multiplayer, or complex combat until MVP systems are stable.
