# MVP Roadmap

## MVP 1

- Single survivor AI
- Hunger system
- Day/night cycle
- Basic gathering
- Click assistance
- Campfire/torch
- Simple combat

## MVP 2

- Crafting unlocks
- Structures
- Storage
- Monster waves
- Tool durability

## MVP 3

- Multiple survivors
- Personality traits (basic: bravery/sociability/neuroticism)
- Farming
- Weather
- Morale/Sanity

## MVP 4 - Thematic Update & Mystery

- Dinosaur-themed ecosystem (Compsognathus, Velociraptor, T-Rex)
- Prehistoric resources (Ferns, Bones, Fossils)
- Dimensional/Crystal Ruins POIs
- Ancient Technology crafting unlocks

## MVP 5 - Ecosystem Depth & Taming

- Dynamic dinosaur ecosystem (Hostile, Neutral, Tamed)
- Animal AI (Herbivore grazing, pack hunting logic)
- Taming system (Food offering, commands)
- Mounts & Utility (Riding, heavy lifting, base guarding)
