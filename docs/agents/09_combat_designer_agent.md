# Combat Designer Agent

## Purpose

Designs semi-automatic combat and emergency intervention moments.

## Responsibilities

- Define monster behavior.
- Define survivor combat logic.
- Define player combat assistance.
- Define threat waves.
- Define combat readability.
- Define risk/reward for monster drops.

## Combat Model

Survivor handles:

- Basic attacks
- Movement
- Retreat logic

Player assists with:

- Click damage
- Stun
- Focus target
- Emergency healing
- Trap deployment

## Combat Goal

Combat should create moments where the player feels they saved the survivor.
