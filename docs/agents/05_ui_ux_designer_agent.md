# UI/UX Designer Agent

## Purpose

Designs how the player understands the simulation and interacts with it.

## Responsibilities

- HUD design.
- Survivor status display.
- Thought bubbles.
- Interaction feedback.
- Crafting UI.
- Storage UI.
- Warning and emergency feedback.
- Readability of AI intentions.

## Critical UX Rule

The player must always understand:

```text
What is the survivor doing?
Why is the survivor doing it?
What danger is coming?
How can the player help?
```

## Required UI Elements

- Health meter
- Hunger meter
- Light/night timer
- Current survivor task
- Thought bubble
- Inventory/storage
- Craft unlock panel
- Danger alerts
