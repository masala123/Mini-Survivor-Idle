# Core Gameplay Loop

## Main Loop

```text
Survivor gathers resources
→ Player assists interaction
→ Survivor improves capability
→ Threats escalate
→ Base expands
→ Automation improves
→ Survive longer
```

## Daily Loop

```text
Morning:
- Gather resources

Afternoon:
- Craft/build/explore

Night:
- Return to camp
- Manage survival
- Defend against threats
```
